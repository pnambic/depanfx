# Congratulations

You've used DepanFX's analysis tools to visualize the structure of a Java application.

## DepanFX Concepts

This introduction to DepanFX's lists and views analysis tools starts
down the path of learning to use DepanFX's powerful visualization tools.

This section introduced a number of DepanFX's basic concepts and features.

* Node lists allow you to focus on the components of interest.
* Node view provide flexible rendering of nodes and their relationships.
* The Built-In project provides a number of artifacts for general use.

### Panel Types

The UX DepanFX's list and view analysis tools are provided by two panels.

* The Node List panel: displays a list of nodes from a dependency graph.
* The Node View panel: displays a diagram of the nodes and their relationships.

### File Types

DepanFX uses many different file types to store data.
With node lists and view, the primary file types are:

* `.dnli` - Node Lists
* `.dnvi` - Node Lists
