# Release `v0.0.0-j`
***Sep-2025***

Release v0.0.0-j advances DepanFX with broad improvements across
the entire application.

# User Targeted Changes

The major areas of user visible improvement include:

- Node info annotations: In an extension of the node info behavior,
nodes can be associated with multiple text annotations.
The [Node Annotations](../reference/nodelist/NodeAnnotations.md) page
provides details on these capabilities.

- View panel edge matchers: The view panel adds edge filters,
providing a more precise mechanism to indicate the edges of interest.
The [View Panel Edge Filters](../reference/nodeview/ViewPanelEdgeFilters.md)
page provides details on these capabilities.

- Node list edge matcher: This new kind edge matcher
allows selection of edges based on head or tail nodes.
This pairs wonderfully with the view panel's new edge filters,
allowing one focus one the edges related to specific components.
The [Edge Filters](../reference/nodelist/EdgeMatchers.md) page
provides details on these capabilities.

- View Panel flight controls: The viewpoint for rending the nodes
in the graph is now base on "flight controls".
Instead of moving along the absolute x, y, and z axis,
the viewpoint is based on a line of travel and a line of sight.
The provides a more natural way to focus on areas that appear interesting.
You fly there.
The [Flight Controls](../reference/nodeview/keyboard_cmnds/KeyboardCommands.md)
page describes the actions for various keys.

- Node folding:  Node folding allows the definion of explicit
nest and member relations for nodes \[[reference](../reference/nodelist/NodeFoldings.md)\].
Hierarchies from derived trees in node list views can be saved
as node foldings and reused with the view panel
to expose interdependencies at higher levels of composition.

- Node foldings with node view:
When a node folding is attached to a node view,
many of the member nodes are hidden, with edges promoted to the visible nodes
\[[reference](../reference/nodeview/ViewPanelNodeFoldings.md)\].
This can expose unexpected interdependencies among components
at a higher level of composition.

- View panel hit testing:  Mouse selection of nodes within the view panel
should be much more reliable.  Area selections (shift+drag) in particular
should do the right thing.

- Node view merge:  Multiple view panel definitions files
can be merged into a single view panel definition.
Node traits, such as location,
are merged into the resulting view definition file.
This can help when a large system is layed out in sections
for separate analysis work.

- User interface improvements:  In addition to a much friendly
and more helpful Welcome panel, there are a number of smaller
user interface improvements throughout DepanFx.
These include better sizing of dialog box, better choices for implicit
names, and menu system refinements for multi-choice operations.

Full detail should be available in the reference sections for these features. 

# Internal Changes

Mostly smaller tweaks or user interface changes, these are included
in the interests of completeness.

## Hit Testing Now Works

A new scheme for hit testing has been implemented,
and it is much more reliable.
Individual mouse clicks tended to work,
but the items selected in a drag selection could be very random.

The new color-coding mechanism for hit testing is fast and consistent.
Note that if a node is completely obstructed by neighbors
and is underneath them all, that node is hard to select with the mouse.

## Version Updates

DepanFX targets Java 21 with JavaFX 23 and the latest Spring and Guava releases.

DepanFX should work on any platform with a Java 21 JVM.
The OpenGL and JavaFX libraries include modules for
Windows, MacOs, and Linux.

## Performance Improvements

Various upgrades to the rendering layer (VBOs, etc)
provide approximate 30% more frames per second (fps).

## Release Testing

Testing focused on Windows 10 with Java 21.
Functionality appears stable,
but broader platform coverage is encouraged before wider distribution.
