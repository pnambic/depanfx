# Release `v0.0.0-k`
***Oct-2025***

Release v0.0.0-k fixes the Windows launch problem for DepanFX.

# User Targeted Changes

The Windows targets launch script `DepanFx.bat` should now work as expected
of Window 10 and Window 11 operating systems.
A temp file is used to bundle the Java JVM's launch arguments.
This avoids many problems created by Windows limited command line length.

## Release Testing

Testing focused on Windows 10 with Java 21.
Additional launch testing completed with Windows 11 and CygWin.
