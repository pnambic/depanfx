# DepanFX
DepanFX is a direct manipulation tool for visualization, analysis,
and refactoring of dependencies in large applications.

## DepanFX Releases
Watch this space for information about pre-packaged releases.

If your development environment supports Gradle and Java 21,
you should be able to build an executable a few minutes.

## DepanFX Features

* Direct manipulation of heterogeneous dependency information.
* Analysis and visualization of very large applications.
* For Java, dependency discovery at the class member level.
* Selection of nodes by type, edge-count, and paths.
