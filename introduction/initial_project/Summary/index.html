Congratulations

You've gotten your first DepanFX project up and running.

With the project and a dependency graph, it will be straightforward to return to the system under analysis for future engineering work.

That's the goal for the next tutorial - learning the basic of the DepanFX's primary analysis tools.

Now it's time to start your first analysis.

DepanFX Concepts

This Getting Started guide introduced a number of DepanFX's basic concepts and features.

  • Work within DepanFX is based on a session that contains projects.
  • Dependency graphs can be constructed from various sources.

Panel Types

DepenFX provides four main panel types:

  • The Welcome panel: provides a cheery welcome to DepanFX.
  • The Workspace panel: presents a collection of projects.

File Types

DepanFX uses many different file types to store data. Mostly, the UX will guide your use of these file types with the proper context. Regardless, it can be good to know what you are looking at

  • .dgi - Dependency Graphs
